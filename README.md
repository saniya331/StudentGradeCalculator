# Student Grade Calculator

## 📌 Project Overview

The Student Grade Calculator is a simple Java console application that allows users to enter marks for multiple subjects, calculate the total marks, average percentage, and determine the student's grade based on the average score.

This project is developed using Core Java and demonstrates basic programming concepts such as variables, user input, conditional statements, and arithmetic operations.

---

## 🚀 Features

- Enter marks for multiple subjects.
- Calculate total marks.
- Calculate average percentage.
- Display grade based on average.
- Simple and user-friendly console interface.
- Input validation for marks (optional enhancement).
